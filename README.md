# MINI NETWORK AUTOMATION PROJECT

## PURPOSE
Checks whether Cisco network devices are **UP** or **DOWN**, and displays the
result

## FILES
inventory.json    | List of devices
network_check.py  | Main Program
output.json       | Results Generated
README.md         | Documentation

## REQUIREMENTS
Python 3

## USAGE
Simulated Mode:
    python network_check.py
Live Mode
    python network_check.py --live
